# ADR0018 — immutable colored history inside terminal panes

Status: accepted for 0.0.1-dev; Linux implementation, platform gates remain open.

Ordinary wheel events on a shell without mouse reporting previously did nothing. The separate text-history viewer provided search/copy but did not preserve the terminal's styled cell grid. The BridgeMind terminal lifecycle contract and PigADE terminal foundation require a usable history view without an independent UI parser.

Extend the existing host history worker with OpenGrid/Grid queries. A host-validated session/generation resolves its journal and published durable sequence. The existing restore path freezes one normal-screen snapshot with hot normal rows and indexed cold rows. The same worker, two-snapshot LRU, 120-second idle expiry and explicit Close apply to both text and grid views; no extra parser, host process or journal is introduced. Read-only restoration has no terminal side effects.

Pages preserve physical row order, Unicode scalar sequences, flags, underlines, hyperlinks and each cold row's recorded palette. Hot rows use the frozen normal grid and its palette, including while the source CLI is in alternate screen. Archive boundaries occupy labeled rows. Query dimensions are validated before restore/eviction: 1–128 rows, 1–1024 columns, at most32768 cells. The terminal adapter bounds one projected row to1MiB before payload copying. The host bounds page copying to8MiB and exact JSON output to4MiB with a nonallocating bounded writer, below the existing8MiB IPC frame. Oversized payloads fail explicitly; nothing is silently truncated to satisfy the budget. Maximum ordinary128×256 UI geometry is covered by a real serialization test.

The UI keeps one historical pane at a time; other panes continue displaying live output and accept input. It never replaces the live State replica. Accepted typed pages are projected once into a separate cached renderer View. Per-row explicit palette overrides become RGB cell colors; symbolic renderer defaults remain named/indexed so cached pages can follow local terminal palette changes without rereading history. This is not ANSI parsing or reflow. Cursor and input modes are disabled in this display replica. Header, accessible terminal name and status distinguish history, sequence, loading/error and clipped historical widths. A mouse/keyboard Return to Live action removes the replica and closes its lease. Stale/late replies cannot change a different generation; late opens are closed. Wheel/page bursts keep one request in flight plus the latest bounded intent, without retrying failed reads automatically.

Unmodified wheel scrolls normal-screen history when the CLI has not enabled mouse reporting. TUI wheel events retain their existing path; Shift+PageUp explicitly opens normal history. While historical content is selected, wheel, arrows, PageUp/Down and Home navigate it; End/Escape return live. Text, IME commits, paste, file insertion and terminal mouse events cannot reach that historical target. No blocked text is replayed on return. Management modifier/prefix operations remain available. Selection/copy use the exact cached cells and physical source widths, excluding viewport padding and retaining source soft-wrap edges; they are reset on page replacement. Native PTY resizing continues from live geometry even while history is displayed.

This does not implement horizontal history panning or cold-history reflow. Rows wider than the viewport are explicitly marked as clipped; the full text remains accessible in the existing text-history viewer. Scroll position/leases are ephemeral across UI restarts; saved generation pins remain separate. Snapshot expiry/errors preserve the displayed read-only frame and offer Return to Live, without disguising it as current output. Global heap admission, storage quotas, complete GPU/platform/a11y gates and the full MVP scenario remain independent work.

Verification covers cold/hot styled-cell projections, palette changes, alternate-screen isolation, physical boundaries, Unicode/wide glyphs, payload limits, full viewport size, immutable replay of pages after live output, wrong generation, stale replies, Home/overscroll anchoring and input isolation. The existing private X11 history fixture provides native wheel/key/return and visual evidence; it does not certify native Wayland or GPU performance.
