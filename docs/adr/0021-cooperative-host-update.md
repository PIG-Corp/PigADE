# ADR0021 — cooperative local host replacement

Status: implemented for Linux 0.0.1-dev. This is local service lifecycle, not a signed package updater.

Replacing a release executable leaves an already running host on its old image. New UI capabilities therefore cannot imply that the server supports them. Inspection compares the installed helper image with the authenticated host's `/proc/PID/exe` bytes, with image-size and time bounds. Same version strings alone do not prove equal builds. Private socket ownership, same-user peer credentials and boot/PID/start_ticks bind the observation; a legacy framing rejection permits read-only List inspection, never signal-based shutdown.

`HostStatus` is metadata-only. `ShutdownIfIdle { expected_incarnation }` is checked inside the serialized host actor after reconciling exits. A retained nonexited process, nonexited durable launch record, queued/inflight Git write or resume verification, catalog/recovery/storage degradation or changed incarnation refuses replacement. Historical cells without a process do not count as live CLI. A resume activity permit spans queue, verification and actor completion. After accepting shutdown the actor seals IPC admission, refuses already queued jobs without dispatching them and releases its existing endpoint/writer locks on exit. A client must not infer exit from acknowledgement alone.

The standalone `host-inspect`, `host-shutdown-idle` and `host-reconcile` commands isolate OS identity checks from the cell-only UI. A reviewed shutdown freezes the peer, socket inode and installed helper identity. Confirmation rechecks them and sends exactly one shutdown request. An explicit actor rejection is distinct from a lost result. Known failures before sending the shutdown request return a definitive refusal. Read-only reconciliation observes whether that exact old identity disappeared, without sending another shutdown or a signal; it remains usable after a helper rebuild. Only confirmed disappearance allows the default startup path to start/reuse a host through existing sole-writer locks. No CLI, native conversation or previous task is automatically started.

UI exposes version/status in a small optional sheet and command palette, never the creation flow. Explicit socket connections retain caller ownership, even when a supplied path happens to equal the default. Updating is available only for an inspected different build and cooperative idle host. UI product commands are withheld while replacing the host or awaiting resolution of an unknown outcome, and window-close coordination includes the pending outcome. A lost result retains its frozen original peer across dialog closure and refresh. Legacy hosts remain read-only; check-then-signal would race another client's launch and is deliberately unsupported.

Private process tests cover stale incarnation/image/socket/peer, active PTY and unresolved launch refusal, concurrent launch versus shutdown, recovered historical journals, and proof of exit followed by nonmutating reconciliation. App tests cover UI eligibility and receipt preservation. Native validation uses the existing isolated setup fixture; it does not certify a universal updater, live-session migration or additional platforms.
