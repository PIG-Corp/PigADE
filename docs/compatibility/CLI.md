These are detection and bounded PTY/CLI-component results, not the final §9.2 two-version certification matrix. Unknown AI versions stay generic. Product startup-context adapters are enabled only for the exact Claude/Codex versions above; automatic resume remains disabled. OpenCode context is disabled until exact-version instruction merge behavior is verified; the current installed executable changed to1.19.3, while the bounded PTY evidence above is for1.18.22. A resume adapter must bind a concrete conversation through documented structured events or explicit user binding, preserve cwd/revision, never use `--last`, and never fall back to a new conversation after resume failure.

Official sources inspected:

- [OpenAI Docs: codex resume](https://learn.chatgpt.com/docs/developer-commands#codex-resume): exact session resume; cwd choice is part of the resume contract, and explicit `--cd` wins over `tui.resume_cwd`. This does not prove the installed version's context receipt or automatic binding.
- [Claude CLI reference](https://code.claude.com/docs/en/cli-reference): interactive launch, exact resume and session-scoped instruction flags. Current docs can describe versions later than the installed binary; help alone does not certify behavior.
- [OpenCode CLI](https://opencode.ai/docs/cli/) and [agents](https://opencode.ai/docs/agents/): session selection and documented role configuration. Actual adapter tests remain required.

No account/login changes or provider-home writes are part of these probes. Real task/resume testing needs dedicated test conversations and recorded versions; it is an open release gate, not silently inferred from local authentication.

Product manual binding (schema6): PigADE records a user-supplied exact conversation ID against one logical session, source generation, launch plan and frozen context. Real-host fake-CLI PTY tests verify save/CAS/reopen and unchanged terminal generations. They do not verify the ID exists at a provider or certify interactive native resume. Generation-head/history selection is implemented separately and does not launch a CLI. Manual Codex0.162.1 native resume is enabled in adapterv2; other provider/version native-resume flags remain disabled. Automatic ID discovery and auto-resume remain pending.

A missing UUID returned “No saved session found” with no new-conversation fallback. Product fake-CLI real-PTY integration separately verifies exact argv/cwd/frozen context, unchanged layout/old frame, pin clearing, duplicate attempt rejection and stale-binding refusal. This is narrow manual transport support; full product/reboot, account-mismatch, deleted-dialogue and previous-version certification remain open.
