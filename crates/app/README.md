# PigADE application — 0.0.1-dev

Held panel control defaults to Ctrl: Q closes placement while leaving CLI running, F toggles focus mode, arrows focus, Shift+arrows swap, Left/Right mouse drag moves/resizes from the terminal body, 1–9 select tabs, Shift+1–9 transfer, Tab/Shift+Tab cycle tabs, Enter opens shell. Header `Ctrl ▾` or palette opens the optional modifier selector (keys1–5); choices Ctrl/Alt/Super/Ctrl+Alt/prefix-only persist in the bounded UI-local `${XDG_CONFIG_HOME:-$HOME/.config}/pigade/controls.json`. Ctrl+C/D/Z/R and unbound combinations still reach CLI; Ctrl+F/Q/arrows/brackets are reserved in the Ctrl profile. Editing dialogs and AltGr prefer-character events retain their input paths. The original management prefix remains available. Reproduce private native checks with `python3 scripts/isolated-ime-x11.py --run --fixture controls --output /fresh/private/path`.

The native GPUI application displays cell replicas from the independent Rust session host. It contains no ANSI parser or terminal core dependency. Host-owned frames carry generation/sequence identity; same-generation sequence regression is rejected. Closing UI leaves host and CLI processes running. Disconnection preserves the last frame as read-only history. Input is never automatically retried. A proven host queue-full rejection can be acknowledged with Ctrl+Shift+Space then Escape; later queued requests are counted as unsent, and unknown outcomes stay locked. See the [command rejection contract](../../docs/reports/app-command-rejection.md).

This is the application under development, not a separate comparison stand. Project/workspace/tab navigation, saved tiling, drag/drop/resize and reviewed startup context are connected to the real host. Terminal/recovery/platform gates and the full MVP remain open.

The palette searches placed panels across Ready workspaces by display name, provider, frozen role, known state and project/workspace/tab. Arrow keys and Enter select the same rows as mouse clicks; explicit next/first controls page through64 panel results. Search replies bind the dialog/query/editor revision. Activation atomically selects the destination scope and focus without changing generation pins or spawning a process. Rename panel stores a revisioned local alias (128 characters/512 UTF-8 bytes, empty resets); it does not write the CLI title or context. These additive features require the host's pane-label capability; older hosts remain running with the feature unavailable.

“Остановить CLI” in the pane menu/palette (`stop`) opens a compact confirmation bound to the exact session and process generation. Hidden sessions have a separate Stop action alongside Attach, with arrow/Tab/Enter navigation. Confirmation retains pane placement/history; accepting a request is distinct from observing that generation as exited. Lost replies trigger only readonly state checks, never another Stop. Closing the sheet after confirmation does not undo the request. History/degraded states leave completion explicitly unconfirmed. The current Unix PTY adapter signals the top-level CLI process; it does not guarantee termination of all descendants.

Local queue saturation reports that the current input was not accepted and allows subsequent input once capacity returns; it never retries rejected bytes. Intermediate mouse motion leaves eight of the32 receipt slots for keys and button transitions. This local backpressure does not acknowledge host rejections or unlock unknown outcomes. Solid Unicode block elements are drawn against device-aligned cell geometry, keeping OpenCode logos and borders continuous when font and row heights differ; shade patterns retain font rendering.

Idle updates use conditional polling: the host returns only selection metadata
when generation/sequence/lifecycle state is unchanged. Cached cell allocations
are retained, and the UI checks a lightweight revision before cloning or
notifying GPUI. A current host advertises generation selection and uses additive `poll_panels` with one exact generation or authoritative head per logical pane; older compatible hosts retain `poll_visible`. Unsupported protocol versions produce an explicit capability error;
the app never automatically restarts a host for a capability error. Only sessions placed in the active tab are selected for cell polling; hidden sessions retain their PTYs.

## Build and headless verification

Install Rust and the official GPUI Linux prerequisites documented in [the recorded source check](../../docs/research/gpui-source-check/README.md). From the repository root:

```sh
crates/app/bootstrap.sh build --locked
crates/app/bootstrap.sh test --locked
crates/app/bootstrap.sh clippy --locked --all-targets -- -D warnings
crates/app/bootstrap.sh fmt -- --check
```

Bootstrap verifies the pinned archive SHA-256, extracts it into ignored `.upstream`, applies the [manifest-pinned X11 focus profile](patches/gpui-x11-ime/) with exact pre/postimage checks, and uses the application's own Cargo.lock. Mixed or unexpected patched sources fail closed; an already applied exact profile is accepted. The separate dependency workspace preserves GPUI's compatible dependency graph; it does not introduce a second terminal implementation. Default output is `crates/app/target`. `PIGADE_GPUI_CACHE`, `PIGADE_GPUI_CARGO_HOME` and `PIGADE_GPUI_TARGET_DIR` can override build cache locations. None of these commands opens a window.

After building the host and app, run without arguments to start/reuse a private independent host. An explicit socket connects without starting a host:

```sh
crates/app/target/debug/pigade-app /absolute/state/host.sock
```

Move the pointer over a panel body or header to focus it without clicking. A stationary pointer does not override keyboard focus; dialogs, text selection, active IME preedit, management gestures and inactive windows suppress hover. Focus writes coalesce to one in-flight request plus the latest intent; an older ACK does not change the local input target. Ctrl+LMB tears the pane out of tiling into an85% preview retaining the original relative grab point (including header/edge grabs); remaining tiles fill its old slot. Drop inserts a new sibling split using target aspect ratio and pointer half, never center-swap. Preview leaves host placement and PTY rows/cols unchanged; Escape cancels. Reproduce the isolated four-shell pointer/IME/dialog/undo fixture with `python3 scripts/isolated-ime-x11.py --run --fixture pointer --output /fresh/private/path`. Ctrl+Shift+Space enters PigADE management mode; project/tab/tiling shortcuts are listed in the [root instructions](../../README.md). Terminal selection/copy/paste are available from the palette and footer. Escape exits/acknowledges rejected local input. Left-drag selects cells; Shift overrides CLI mouse reporting for local selection. See [mouse input](../../docs/reports/mouse-input.md) and [selection/paste](../../docs/reports/selection-and-paste.md) for exact behavior and verification limits. Outside management mode ordinary CLI keys go to the focused running generation. Printable text is delivered through GPUI's committed-text input handler; preedit stays local. A fixed EN/RU and CLI shortcut sequence now passes in the actual private X11 release app, including a repaired Alt+X path; see the [keyboard report](../../docs/reports/x11-keyboard-20261017.md). One actual X11/Fcitx Pinyin commit passes in private debug/release runs with no precommit bytes or duplicate input; One callback-preedit capture is now visually verified; full shortcut/positioning coverage and cross-session composition barriers remain open. See the [X11 report](../../docs/reports/x11-ime-20261017.md).

## Known limits

The UI follows the active tab’s host-owned tiling tree and stable session IDs. Projects, shared/worktree workspaces, tabs, drag/drop, transfer and saved undo/redo are integrated. A reviewed launch freezes the effective context; exact-version Claude/Codex startup arguments are implemented with unconfirmed model receipt. OpenCode and unknown versions require explicit launch without context. Context fields now support native shaped multiline editing, selection, clipboard, Unicode-aware navigation and bounded undo/redo; saved revisions preserve later typing. Prefix E opens workspace context, Shift+E project context. Explicit user conversation binding is integrated through prefix B and the palette, with frozen cwd/executable/context provenance and CAS save. Exact canonical UUIDs (Codex/Claude) and ses_ IDs (OpenCode) are stored without touching provider files; existence is unverified. Manual exact-ID resume is implemented for Codex0.162.1 through a read-only review and the durable launch gate. Automatic resume, other provider/version support, updates to running sessions remain pending. Indexed read-only history paging/search is integrated through prefix I, the palette and the pane menu. The new conversation sheet lacks isolated visual acceptance. Startup memory now has a revision/hash-bound Markdown section picker, explicit 32KiB UTF-8 counter, keyboard number entry and preview gating; Ctrl+Shift+R explicitly reloads the source and clears the choice. The workspace-context editor has an actual private X11/Fcitx input/edit/undo/save fixture: `python3 scripts/isolated-ime-x11.py --run --fixture context --output /fresh/private/path`. Its screenshot was inspected; this one sequence does not certify broader IME/reset, mouse/clipboard, Wayland or accessibility behavior. One private native X11 shell-launch review fixture also selects section2 from a40KiB memory document, validates the exact43-byte frozen section and confirms that no new PTY was launched; the final review with fixed footer was visually inspected. Reproduce with `python3 scripts/isolated-ime-x11.py --run --fixture memory --output /fresh/private/path`. Provider-specific, small-window and full accessibility review cases remain open. Visible frame selection, explicit bounded clipboard paste and mode-aware mouse input are implemented; native platform gestures/clipboard remain unverified. Selection clears on a new frame sequence, and paste is limited to one16KiB input command including brackets. Host metadata is polled with a50ms idle interval; commands wake the worker immediately and state/receipt notifications wake the UI. Complete JSON cell frames are sent only after the generation watermark changes. There is no release input-to-present, frame-time, idle CPU/GPU or RSS acceptance measurement. Cell flags/basic colors and typed dynamic palette overrides are rendered (see [palette report](../../docs/reports/dynamic-palette.md)), and typed block/underline/beam/hidden cursor state is rendered (see [cursor report](../../docs/reports/terminal-cursor.md)); underline variants, explicit underline color and strikeout also render (see [decoration report](../../docs/reports/terminal-decorations.md)). Font-exact decoration metrics and full Unicode coverage remain open. A private Wayland AT-SPI probe sees named application, heading, selected terminal and status nodes. It does not expose complete terminal Text/Action interfaces or certify Orca. One native X11 IME sequence is verified; the complete X11/Wayland input and reset matrix, fractional scaling/multi-monitor, GPU-loss and light-theme checks remain open. Historical active-desktop smoke evidence is not platform certification. See [ADR0007](../../docs/adr/0007-gpui-accessibility-platform-upgrade.md) for the source-upgrade decision and acceptance boundary.

Automated windows, focus manipulation and keyboard/mouse injection on the active user desktop are forbidden. The unsafe smoke script has been removed. Future UI automation requires a verified isolated compositor or VM. Read [the incident report](../../docs/reports/desktop-incident.md) before platform work; do not reuse its historical actions as test instructions.
