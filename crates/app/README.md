# PigADE application — 0.0.1-dev

Terminal clipboard shortcuts Ctrl+Shift+C/V copy the selection and request paste independently of the panel modifier profile; ordinary Ctrl+C/V remain CLI input. Pinned Linux GPUI reads the OS clipboard synchronously; a ready async task does not make that platform read nonblocking. Its X11 clipboard backend currently exposes text/images, not OS URI-list file entries; native file drop is the supported file-manager path route on this backend. Clipboard/platform latency remains an acceptance gap.

Held panel control defaults to Ctrl: Q closes placement while leaving CLI running, F toggles focus mode, arrows focus, Shift+arrows swap, Left/Right mouse drag moves/resizes from the terminal body, 1–9 select tabs, Shift+1–9 transfer, Tab/Shift+Tab cycle tabs, Enter opens shell. Header `Ctrl ▾` or palette opens the optional modifier selector (keys1–5); choices Ctrl/Alt/Super/Ctrl+Alt/prefix-only persist in the bounded UI-local `${XDG_CONFIG_HOME:-$HOME/.config}/pigade/controls.json`. Ctrl+C/D/Z/R and unbound combinations still reach CLI; Ctrl+F/Q/arrows/brackets are reserved in the Ctrl profile. Editing dialogs and AltGr prefer-character events retain their input paths. The original management prefix remains available. Reproduce private native checks with `python3 scripts/isolated-ime-x11.py --run --fixture controls --output /fresh/private/path`.

The native GPUI application displays cell replicas from the independent Rust session host. It contains no ANSI parser or terminal core dependency. Host-owned frames carry generation/sequence identity; same-generation sequence regression is rejected. Closing UI leaves host and CLI processes running. Disconnection preserves the last frame as read-only history. Input is never automatically retried. A proven host queue-full rejection can be acknowledged with Ctrl+Shift+Space then Escape; later queued requests are counted as unsent, and unknown outcomes stay locked. See the [command rejection contract](../../docs/reports/app-command-rejection.md).

This is the application under development, not a separate comparison stand. Project/workspace/tab navigation, saved tiling, drag/drop/resize and reviewed startup context are connected to the real host. Terminal/recovery/platform gates and the full MVP remain open.

The Git sheet supports explicit per-file Stage/Unstage from the frozen diff ticket with Ctrl+S. The host revalidates HEAD, index, file, status and workspace binding, builds a private candidate index, and uses native `index.lock` CAS; it never overwrites the worktree or retries automatically. Operation receipts survive closing the sheet and host restart. Ctrl+R inspects an uncertain result or refreshes; Ctrl+Shift+R explicitly acknowledges viewing Unknown/Unavailable. File/index caps are256KiB/8MiB, with8 leases for10 minutes and4096 receipts. Sparse/split index, symlink and conflict entries are unsupported; explicit Stage can invoke normal Git clean/EOL filters. Discard, pull, push, Stage All and live watching remain absent; Git MVP is incomplete.

Create Commit or Ctrl+Enter in the Git list opens a frozen staged-file review and message. Ctrl+Enter there starts native Git once; hooks and configured signing remain enabled. Stale HEAD/index is rejected. Running results are inspected while the matching sheet is open; lost outcomes remain Unknown and are never automatically repeated. Receipts survive host restart, drafts only survive dialog close in this UI process (16 workspace drafts,32KiB editor bound; Start validates8192 UTF-8 bytes). A host without commit_schema=1 disables commit without restart. This slice requires Linux and native Git2.55.0, attached local/unborn branches and ordinary nonconflicted nonsparse/nonsplit indexes. See [ADR0015](../../docs/adr/0015-guarded-native-git-commit.md) for bounds, proofs and recovery.

The palette searches placed panels across Ready workspaces by display name, provider, frozen role, known state and project/workspace/tab. Arrow keys and Enter select the same rows as mouse clicks; explicit next/first controls page through64 panel results. Search replies bind the dialog/query/editor revision. Activation atomically selects the destination scope and focus without changing generation pins or spawning a process. Rename panel stores a revisioned local alias (128 characters/512 UTF-8 bytes, empty resets); it does not write the CLI title or context. These additive features require the host's pane-label capability; older hosts remain running with the feature unavailable.

“Остановить CLI” in the pane menu/palette (`stop`) opens a compact confirmation bound to the exact session and process generation. Hidden sessions have a separate Stop action alongside Attach, with arrow/Tab/Enter navigation. Confirmation retains pane placement/history; accepting a request is distinct from observing that generation as exited. Lost replies trigger only readonly state checks, never another Stop. Closing the sheet after confirmation does not undo the request. History/degraded states leave completion explicitly unconfirmed. The current Unix PTY adapter signals the top-level CLI process; it does not guarantee termination of all descendants.

Local queue saturation reports that the current input was not accepted and allows subsequent input once capacity returns; it never retries rejected bytes. Intermediate mouse motion leaves eight of the32 receipt slots for keys and button transitions. This local backpressure does not acknowledge host rejections or unlock unknown outcomes. Solid Unicode block elements are drawn against device-aligned cell geometry, keeping OpenCode logos and borders continuous when font and row heights differ; shade patterns retain font rendering.

Idle updates use conditional polling: the host returns only selection metadata
when generation/sequence/lifecycle state is unchanged. Cached cell allocations
are retained, and the UI checks a lightweight revision before cloning or
notifying GPUI. A current host advertises generation selection and uses additive `poll_panels` with one exact generation or authoritative head per logical pane; older compatible hosts retain `poll_visible`. Unsupported protocol versions produce an explicit capability error;
the app never automatically restarts a host for a capability error. Only sessions placed in the active tab are selected for cell polling; hidden sessions retain their PTYs.

## Build and headless verification

Install Rust and the official GPUI Linux prerequisites documented in [the recorded source check](../../docs/research/gpui-source-check/README.md). From the repository root:

```sh
crates/app/bootstrap.sh build --locked
crates/app/bootstrap.sh test --locked
crates/app/bootstrap.sh clippy --locked --all-targets -- -D warnings
crates/app/bootstrap.sh fmt -- --check
```

Bootstrap verifies the pinned archive SHA-256, extracts it into ignored `.upstream`, applies the [manifest-pinned X11 focus profile](patches/gpui-x11-ime/) with exact pre/postimage checks, and uses the application's own Cargo.lock. Mixed or unexpected patched sources fail closed; an already applied exact profile is accepted. The separate dependency workspace preserves GPUI's compatible dependency graph; it does not introduce a second terminal implementation. Default output is `crates/app/target`. `PIGADE_GPUI_CACHE`, `PIGADE_GPUI_CARGO_HOME` and `PIGADE_GPUI_TARGET_DIR` can override build cache locations. None of these commands opens a window.

After building the host and app, run without arguments to start/reuse a private independent host. An explicit socket connects without starting a host:

```sh
crates/app/target/debug/pigade-app /absolute/state/host.sock
```

Move the pointer over a panel body or header to focus it without clicking. A stationary pointer does not override keyboard focus; dialogs, text selection, active IME preedit, management gestures and inactive windows suppress hover. Focus writes coalesce to one in-flight request plus the latest intent; an older ACK does not change the local input target. Ctrl+LMB picks up immediately; header drag waits for more than10px travel, then tears the pane out of tiling into an85% preview retaining the original relative grab point (including header/edge grabs); remaining tiles fill its old slot. Drop inserts a new sibling split using target aspect ratio and pointer half, never center-swap. Canvas gutters select the nearest target; focus-mode drag temporarily reveals the remainder without changing its saved mode. Hidden panes retain geometry slots, so their CLI identities cannot be reassigned by focus mode. Preview leaves host placement and PTY rows/cols unchanged; Escape cancels. Drop onto a different visible tab in the same Ready workspace shows clipped target highlighting and a bounded destination-layout thumbnail. Empty tabs receive a first pane; occupied tabs insert it to the right of their focused pane. Release uses the host's atomic TransferAndActivate with layout/selection CAS, preserves process/generation identity and follows the destination. Undo restores both trees without selecting the source. This additive action requires pane_tab_drop_schema=1; older hosts disable the drop target without restart. Reproduce the isolated four-shell pointer/IME/dialog/undo fixture with `python3 scripts/isolated-ime-x11.py --run --fixture pointer --output /fresh/private/path`. Ctrl+Shift+Space enters PigADE management mode; project/tab/tiling shortcuts are listed in the [root instructions](../../README.md). Terminal selection/copy/paste are available from the palette and footer. Escape exits/acknowledges rejected local input. Left-drag selects cells; Shift overrides CLI mouse reporting for local selection. See [mouse input](../../docs/reports/mouse-input.md) and [selection/paste](../../docs/reports/selection-and-paste.md) for exact behavior and verification limits. Outside management mode ordinary CLI keys go to the focused running generation. Printable text is delivered through GPUI's committed-text input handler; preedit stays local. A fixed EN/RU and CLI shortcut sequence now passes in the actual private X11 release app, including a repaired Alt+X path; see the [keyboard report](../../docs/reports/x11-keyboard-20261017.md). One actual X11/Fcitx Pinyin commit passes in private debug/release runs with no precommit bytes or duplicate input; One callback-preedit capture is now visually verified; full shortcut/positioning coverage and cross-session composition barriers remain open. See the [X11 report](../../docs/reports/x11-ime-20261017.md).

The new conversation sheet lacks isolated visual acceptance. Startup memory now has a revision/hash-bound Markdown section picker, explicit 32KiB UTF-8 counter, keyboard number entry and preview gating; Ctrl+Shift+R explicitly reloads the source and clears the choice. Visible frame selection, explicit bounded clipboard paste and mode-aware mouse input are implemented; native platform gestures/clipboard remain unverified.
