# PigADE application — 0.0.1-dev

The native GPUI application displays cell replicas from the independent Rust session host. It contains no ANSI parser or terminal core dependency. Host-owned frames carry generation/sequence identity; same-generation sequence regression is rejected. Closing UI leaves host and CLI processes running. Disconnection preserves the last frame as read-only history. Input is never automatically retried. A proven host queue-full rejection can be acknowledged with Ctrl+Shift+Space then Escape; later queued requests are counted as unsent, and unknown outcomes stay locked. See the [command rejection contract](../../docs/reports/app-command-rejection.md).

This is the application under development, not a separate comparison stand. Project/workspace/tab navigation, saved tiling, drag/drop/resize and reviewed startup context are connected to the real host. Terminal/recovery/platform gates and the full MVP remain open.

Idle updates use conditional polling: the host returns only selection metadata
when generation/sequence/lifecycle state is unchanged. Cached cell allocations
are retained, and the UI checks a lightweight revision before cloning or
notifying GPUI. This requires a current host with the additive `poll_visible` command;
an older host produces an explicit protocol/capability error, never an automatic
host restart. Only sessions placed in the active tab are selected for cell polling; hidden sessions retain their PTYs.

## Build and headless verification

Install Rust and the official GPUI Linux prerequisites documented in [the recorded source check](../../docs/research/gpui-source-check/README.md). From the repository root:

```sh
crates/app/bootstrap.sh build --locked
crates/app/bootstrap.sh test --locked
crates/app/bootstrap.sh clippy --locked --all-targets -- -D warnings
crates/app/bootstrap.sh fmt -- --check
```

Bootstrap verifies the pinned archive SHA-256, extracts it into ignored `.upstream`, applies the [manifest-pinned X11 focus profile](patches/gpui-x11-ime/) with exact pre/postimage checks, and uses the application's own Cargo.lock. Mixed or unexpected patched sources fail closed; an already applied exact profile is accepted. The separate dependency workspace preserves GPUI's compatible dependency graph; it does not introduce a second terminal implementation. Default output is `crates/app/target`. `PIGADE_GPUI_CACHE`, `PIGADE_GPUI_CARGO_HOME` and `PIGADE_GPUI_TARGET_DIR` can override build cache locations. None of these commands opens a window.

After building the host and app, run without arguments to start/reuse a private independent host. An explicit socket connects without starting a host:

```sh
crates/app/target/debug/pigade-app /absolute/state/host.sock
```

Click a panel to focus it. Ctrl+Shift+Space enters PigADE management mode; project/tab/tiling shortcuts are listed in the [root instructions](../../README.md). Terminal selection/copy/paste are available from the palette and footer. Escape exits/acknowledges rejected local input. Left-drag selects cells; Shift overrides CLI mouse reporting for local selection. See [mouse input](../../docs/reports/mouse-input.md) and [selection/paste](../../docs/reports/selection-and-paste.md) for exact behavior and verification limits. Outside management mode ordinary CLI keys go to the focused running generation. Printable text is delivered through GPUI's committed-text input handler; preedit stays local. A fixed EN/RU and CLI shortcut sequence now passes in the actual private X11 release app, including a repaired Alt+X path; see the [keyboard report](../../docs/reports/x11-keyboard-20261017.md). One actual X11/Fcitx Pinyin commit passes in private debug/release runs with no precommit bytes or duplicate input; The full shortcut matrix, inline preedit and cross-session composition barriers remain open. See the [X11 report](../../docs/reports/x11-ime-20261017.md).

## Known limits

The UI follows the active tab’s host-owned tiling tree and stable session IDs. Projects, shared/worktree workspaces, tabs, drag/drop, transfer and saved undo/redo are integrated. A reviewed launch freezes the effective context; exact-version Claude/Codex startup arguments are implemented with unconfirmed model receipt. OpenCode and unknown versions require explicit launch without context. Context fields now support native shaped multiline editing, selection, clipboard, Unicode-aware navigation and bounded undo/redo; saved revisions preserve later typing. Prefix E opens workspace context, Shift+E project context. Explicit user conversation binding is integrated through prefix B and the palette, with frozen cwd/executable/context provenance and CAS save. Exact canonical UUIDs (Codex/Claude) and ses_ IDs (OpenCode) are stored without touching provider files; existence is unverified. Native resume, updates to running sessions and user-facing indexed history are pending. The new conversation sheet lacks isolated visual acceptance. Startup memory now has a revision/hash-bound Markdown section picker, explicit 32KiB UTF-8 counter, keyboard number entry and preview gating; Ctrl+Shift+R explicitly reloads the source and clears the choice. The workspace-context editor has an actual private X11/Fcitx input/edit/undo/save fixture: `python3 scripts/isolated-ime-x11.py --run --fixture context --output /fresh/private/path`. Its screenshot was inspected; this one sequence does not certify broader IME/reset, mouse/clipboard, Wayland or accessibility behavior. One private native X11 shell-launch review fixture also selects section2 from a40KiB memory document, validates the exact43-byte frozen section and confirms that no new PTY was launched; the final review with fixed footer was visually inspected. Reproduce with `python3 scripts/isolated-ime-x11.py --run --fixture memory --output /fresh/private/path`. Provider-specific, small-window and full accessibility review cases remain open. Visible frame selection, explicit bounded clipboard paste and mode-aware mouse input are implemented; native platform gestures/clipboard remain unverified. Selection clears on a new frame sequence, and paste is limited to one16KiB input command including brackets. Host metadata is polled with a50ms idle interval; commands wake the worker immediately and state/receipt notifications wake the UI. Complete JSON cell frames are sent only after the generation watermark changes. There is no release input-to-present, frame-time, idle CPU/GPU or RSS acceptance measurement. Cell flags/basic colors and typed dynamic palette overrides are rendered (see [palette report](../../docs/reports/dynamic-palette.md)), and typed block/underline/beam/hidden cursor state is rendered (see [cursor report](../../docs/reports/terminal-cursor.md)); underline variants, explicit underline color and strikeout also render (see [decoration report](../../docs/reports/terminal-decorations.md)). Font-exact decoration metrics and full Unicode coverage remain open. A private Wayland AT-SPI probe sees named application, heading, selected terminal and status nodes. It does not expose complete terminal Text/Action interfaces or certify Orca. One native X11 IME sequence is verified; the complete X11/Wayland input and reset matrix, fractional scaling/multi-monitor, GPU-loss and light-theme checks remain open. Historical active-desktop smoke evidence is not platform certification. See [ADR0007](../../docs/adr/0007-gpui-accessibility-platform-upgrade.md) for the source-upgrade decision and acceptance boundary.

Automated windows, focus manipulation and keyboard/mouse injection on the active user desktop are forbidden. The unsafe smoke script has been removed. Future UI automation requires a verified isolated compositor or VM. Read [the incident report](../../docs/reports/desktop-incident.md) before platform work; do not reuse its historical actions as test instructions.
