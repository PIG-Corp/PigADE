# GPUI X11 XIM focus lifecycle patch

This profile targets GPUI commit `322cd509dcccaee1f6bc44725d270598ae8171ad` and the exact upstream archive SHA-256 recorded in `manifest.json`. `focus.patch` changes only `xim_handler.rs` and `client.rs`; it adds no upstream files or dependencies.

The patch separates input-method readiness, desired X window focus, and the IC lifecycle. It defers IC creation until both the IM is ready and a nonzero focused window exists, creates at most one IC at a time, and waits for DestroyIC reply before replacing an IC bound to a different window. A late CreateIC reply is destroyed if its original window is no longer the desired focus. Focus is requested only after CreateIC reply and only while its original window remains focused. FocusOut queues UnsetICFocus before ResetIC; same-window refocus reuses the existing IC. XIM key forwarding and commit/preedit/forward-event callbacks are gated on the currently focused IC ID, not merely the active window or an older IC. Failed SetICFocus submission clears local focused state; failed unset/reset/destroy requests never make an IC eligible for forwarding or callbacks.

SetICFocus and UnsetICFocus are one-way XIM requests, so “focused” means the request was successfully sent in order on the XIM connection; the protocol provides no server acknowledgement for either operation. This profile does not certify composition reset/generation barriers, server failure recovery, or all XIM styles. Preedit spot-position behavior remains driven by GPUI's existing `update_ime_position` path and has not been measured by this patch's pure state tests.

Run `python3 scripts/test_gpui_xim_focus.py` to check the archive/preimage hashes, apply the exact patch in a temporary directory, verify postimage hashes, extract the embedded state tests, and execute them with `rustc --test`. This is a no-GUI check; it does not prove live XIM behavior. The root integration owner must apply the profile and run the pinned app build plus isolated IME fixture before making a product-level claim.
