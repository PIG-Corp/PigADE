# Cell-style software captures

Actual debug PigADE app, release host and four real shell PTYs in the existing
verified device-free Weston/Pixman + Lavapipe namespace harness. No desktop input
injection. Each scale directory retains run.json (binary, SDK, font hashes),
result.json (host metadata and process-preserving reopen) and screenshot.

Root visually inspected both PNGs. Source hashes bind the painter/planner and
fixture scripts. Pixel counts identify the explicitly supplied underline RGB;
they do not establish complete pixel equality, a hardware/fractional-scale gate,
input correctness or terminal checkpoint equivalence. Hidden synthetic text
remains in host metadata; the screenshot shows its visible bookends with blank
space between them. Model state never changes to implement cell decoration.
